# Ludo Mood 🎲

An expressive Ludo game for phones. The tokens blink, panic when an enemy is close, cry when captured and wear a crown when they get home. It installs as an app (PWA) and works offline.

**Play:** https://denzeldenys.github.io/Ludo/

## Features
- 2–4 players: any mix of people (pass-and-play) and bots
- Tokens with moods: sleepy, happy, scared, sad, angry, proud
- Player avatars with emoji faces and speech bubbles, plus emoji reactions
- 3D dice, sound effects (synthesised, no audio files), vibration, confetti, screen shake
- Saves automatically, so you can close the app and continue later
- Installable on Android and iPhone, works offline

## Install on your phone
- **Android (Chrome):** open the link, tap **📲 Install app** on the menu (or ⋮ → *Add to Home screen*).
- **iPhone (Safari):** open the link, tap Share → *Add to Home Screen*.

## Files
`index.html` (screens) · `style.css` (look and animations) · `game.js` (rules, bots, effects) · `sw.js` (offline) · `manifest.json` (app install)

No build step: GitHub Pages serves these files as they are.
